4. לקוחות וקובץ הנתונים

עמודות מוכרות

  • sp – שם הלקוח. סלולאר – טלפון. אתר, זהות, Optimac (כתובת MAC).
  • אפשר לשנות אילו עמודות הן שם/טלפון ב ⚙️ ניהול ← 🔤 עמודת שם / 📞 עמודות טלפון. שדות להסתרה: 🙈 שדות מוסתרים.

כרטיס לקוח

  • כפתורים: 📞 התקשר · 💬 וואטסאפ · ✉️ מייל · 📝 קריאה חדשה · 🏘️ אותה חלקה · 🧭 ניווט · 🧾 הצעת מחיר · ✏️ עריכה.
  • מוצגים: קריאות השירות של הלקוח, מיילים שנשלחו (צפייה / שליחה חוזרת / וואטסאפ), אירועי יומן, 🧰 ציוד אצל הלקוח ופרטי הלקוח.
  • שדות ריקים, שדות שערכם 0 והשדה "מזהה" מוסתרים.

ניווט

כפתור 🧭 פותח Waze או Google Maps לכתובת. בפעם הראשונה בוחרים איזו עמודה היא הכתובת (לחיצה ארוכה על 🧭 מחליפה עמודה). אפשר גם ב ⚙️ ניהול ← 🧭 כתובת לניווט.

הוספה, עריכה וייצוא

  • הוספה ועריכה של לקוח מתוך האפליקציה. מחיקה מאושרת בטביעת אצבע.
  • 📤 ייצוא לאקסל ו🔄 עדכון קובץ Access (⚙️ ניהול ← נתוני לקוחות) – בוחרים את קובץ המקור, ואז איפה לשמור (שיתוף / הורדות / קובץ חדש / דריסה / Gmail).

שליחה קבוצתית לחלקה

מכרטיס לקוח ← 🏘️ אותה חלקה ← שליחה קבוצתית בוואטסאפ (אחד אחרי השני) או SMS, עם תבנית לבחירה.

5. זיהוי מתקשר

  • בשיחה נכנסת מופיע חלון עם שם הלקוח ופרטיו – מקובץ הלקוחות, ואם לא נמצא – מאנשי הקשר.
  • שיחות וואטסאפ מזוהות גם הן (דרוש אישור "גישה להתראות").
  • מהחלון אפשר לפתוח כרטיס לקוח או קריאת שירות.
  • בדיקה: ⚙️ ניהול ← 🧪 בדיקת חלונית.

6. שיחות ויומן

  • יומן לשיחות: כל שיחה נרשמת ביומן. אפשר לבחור יומן, ושמירת שיחה: לשאול כל פעם או אוטומטית.
  • סוג רישום ביומן: "יום שלם" (ברירת מחדל – השעה בכותרת, לא חוסם זמן) או "אירוע עם שעה".
  • ❓ מספרים לא מוכרים: לרשום או לא. 📇 זיהוי מאנשי קשר: הפעלה/כיבוי.
  • 📵 שיחה שלא נענתה ← משימה: שיחה שלא נענתה (גם בוואטסאפ) נפתחת כמשימה "📞 לחזור ל…" לאותו יום עבודה – שעה אחרי השיחה, עד 17:00 (שישי 13:00); מחוץ לשעות – יום העבודה הבא ב-09:00. אפשרויות: רק לקוחות ואנשי קשר / כל מספר / כבוי.

7. קריאות שירות

פתיחה

מהמסך הראשי, מכרטיס לקוח, מחלון זיהוי מתקשר, משיתוף טקסט, מהודעת וואטסאפ או ממשימה.

שדות

  • נושא, תיאור (🎤 הכתבה), עדיפות, קטגוריה, סטטוס, ציוד, MAC (בחירה מעמודת Optimac / היסטוריה / 📷 סריקת ברקוד), תאריך מעקב.
  • 👷 אחראי ביצוע – שיוך לאיש צוות (ראו פרק 10).
  • נותן שירות (מיקור חוץ) וסטטוס אצלו (ראו פרק 9).
  • לחיצה ארוכה על שם הלקוח פותחת אותו לעריכה.

מעקב

תאריך מעקב יוצר תזכורת ואירוע ביומן. קריאה שעבר זמן המעקב שלה מופיעה ב"באיחור" (אדום).

סגירה

בסגירה אפשר לשלוח ללקוח סיכום טיפול בוואטסאפ (תבנית "סיכום טיפול ללקוח"), כולל בקשת דירוג 1–5 ⭐ (ניתן לכבות ב ⚙️ ניהול ← ⭐ סקר שביעות רצון).

רשימת הקריאות

כרטיסים עם פס צבע לפי סטטוס: 🔵 פתוח · 🟠 בטיפול · 🟣 ממתין ללקוח · 🟢 ממתין למיקור חוץ · ⚪ סגור · 🔴 באיחור. חיפוש לפי לקוח, נושא, MAC, ספק או איש צוות.

8. עבודה בשטח

  • 📷 תמונות: בכרטיס הקריאה – צלם / מהגלריה. לחיצה פותחת, לחיצה ארוכה מוחקת.
  • ⏱️ שעות וחומרים: טיימר התחל/עצור (מעוגל לרבע שעה), ➕ שעות, ➕ חומר (מהמחירון או חופשי). 🧾 הפק הצעת מחיר / חשבון יוצר הצעה מכל השורות.
  • ✍️ חתימת לקוח: הלקוח חותם באצבע על המסך.
  • 📄 דוח עבודה (PDF): פרטי הקריאה, שעות וחומרים, מה בוצע, תמונות וחתימה – לשליחה בוואטסאפ או במייל.
  • ✅ משימה לקריאה: פותח משימה מקושרת.

9. מיקור חוץ

  • ניהול ספקים: ⚙️ ניהול ← 🏢 נותני שירות; קטגוריות תקלה: 🏷️ קטגוריות; מחירון: 🏷️ מחירון (שם, טלפון, מייל).
  • בקריאה: בוחרים ספק ← שלח בוואטסאפ או במייל (עם תבנית לבחירה, תאריך מעקב, והעתק ללקוח במייל אם רוצים).
  • בהודעת וואטסאפ לספק מצורפת הנחיה לעדכון סטטוס.
  • הספק עונה בוואטסאפ והסטטוס מתעדכן אוטומטית: "בטיפול" / "טופל" / "ממתין לאיסוף" 📦 / "ממתין לאישור" ❓. כל הודעה אחרת נרשמת כהערה. בהתראה: ↩ בטל, ✔ סגור קריאה.
  • כמה קריאות אצל אותו ספק – אפשר לכתוב את המספר: "#15 טופל".

10. אנשי צוות

  • הגדרה: ⚙️ ניהול ← 👷 אנשי צוות (שם וטלפון).
  • בקריאה: 👷 שייך ← שליחה בוואטסאפ עם כל הפרטים וקישור Waze.
  • תשובות: "בטיפול" / "קיבלתי" / 👍 ← בטיפול; "בוצע" / "טופל" / ✅ ← נסגר (עם 💬 סיכום ללקוח בהתראה). הודעה אחרת ← הערה.
  • גם משימות אפשר לשלוח לאיש צוות – תשובת "בוצע" סוגרת את המשימה.

11. וואטסאפ

  • זיהוי שיחות וואטסאפ – חלון זיהוי כמו בשיחה רגילה.
  • 📝 קריאה מהודעות וואטסאפ: הודעה מלקוח מציעה לפתוח קריאה. אפשרויות: לקוחות בלבד / לקוחות + אנשי קשר / כבוי (עדכוני סטטוס מצוות, ספקים והצעות ממשיכים לעבוד).
  • מה זוהה לאחרונה: ⚙️ ניהול ← 💬 זיהוי בוואטסאפ – יומן אבחון של ההודעות האחרונות.
  • תמלול (SpeakApp): משתפים את התמלול לאפליקציה ← מצרפים לקריאה, או לוחצים 📋 הדבק בקריאה.

12. תבניות והודעות

  • ⚙️ ניהול ← ✉️ תבניות הודעה – הודעות מוכנות למייל ולוואטסאפ.
  • שדות שמתמלאים אוטומטית: {שם}, {טלפון}, {אתר}, {זהות}, {MAC}, {נושא}, {תיאור}, {סיכום טיפול} ועוד.
  • מגיעות מוכנות: ממיר לסטרימר, מנוי חדש, שינוי מסלול + סטרימר, ביטול מנוי, סיכום טיפול ללקוח.

13. הצעות מחיר

  • פתיחה מהמסך הראשי, מכרטיס לקוח, מקריאה, או משעות וחומרים.
  • נמען: לקוח מהרשימה, גוף בקיבוץ או מקריאה. מאת: בחירה מרשימת מציעים (🧾 פרטי המציע, ⭐ ברירת מחדל).
  • שורות: מהמחירון (ניתן לייבא מ-Excel) או חופשי. הנחה, תוקף, הערות. מע"מ 18% מתווסף.
  • שליחה: PDF ו/או טקסט, בוואטסאפ או במייל (Gmail / Samsung Email / Outlook).
  • אישור לקוח: הלקוח עונה "מאשר" / "לא מאשר" / 👍 / ❌ / "כרגע משהה" וכד' – בוואטסאפ או בתשובה למייל. הסטטוס מתעדכן אוטומטית, עם ↩ בטל.
  • בתוך ההצעה מופיע כרטיס תשובת הלקוח עם קיצור לשיחה/מייל.
  • הצעה שאושרה ← 🛠️ צור כרטיס שירות מההצעה (גם מתוך ההתראה).

  • ☁️ גיבוי אוטומטי: בוחרים פעם אחת קובץ יעד (למשל ב-Google Drive), ותדירות יומית/שבועית. אם נכשל – מופיעה התראה.
  • שחזור: ⚙️ ניהול ← ♻️ שחזור מגיבוי ובוחרים את קובץ הגיבוי.
💡 מומלץ להפעיל גיבוי אוטומטי יומי ל-Google Drive.

20. אבטחה והרשאות

  • 🔏 אישור מחיקה בטביעת אצבע – לכל מחיקה (לקוח, קריאה, תמונה, משימה…). ניתן לכבות ב-⚙️ ניהול ← הרשאות.
  • כל הנתונים נשמרים בטלפון בלבד, ולא נשלחים לשרת.
  • מסך ⚙️ ניהול ← 🔐 הרשאות מרכז את כולן: טלפון ויומן שיחות, אנשי קשר, יומן, התראות, הצגה מעל אפליקציות, גישה להתראות (וואטסאפ/Gmail), מיקום (לתזכורות לפי מקום), מצלמה (תמונות/סריקה).

בעיהמה לעשות
